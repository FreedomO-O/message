# 문자 모아 인쇄

Android 휴대폰에 저장된 **받은 SMS**를 발신자별로 모아 인쇄하거나 PDF로 저장하는 앱입니다. Android 8.0 이상을 지원합니다.

## APK 다운로드

[시험용 APK 다운로드](https://github.com/FreedomO-O/message/raw/refs/heads/main/downloads/message-print.apk)

파일 크기: 24,527바이트. 디버그 서명된 테스트용 APK입니다. 빌드, 단위 테스트 5개, Android lint(오류 없음)는 통과했지만 가상 기기 시스템 서비스 오류로 실제 앱 실행·문자 조회·인쇄 검증은 완료하지 못했습니다. 실제 휴대폰에서 확인이 필요합니다.

APK와 체크섬은 `downloads/` 폴더에 있습니다.

## 사용 방법

1. APK를 휴대폰에 설치하고 **문자 모아 인쇄**를 실행합니다.
2. **문자 읽기 허용**을 누릅니다. **연락처 이름 허용**은 선택 사항이며, 허용하지 않으면 전화번호로 표시됩니다.
3. 이름 또는 전화번호로 검색하거나 시작일·종료일을 선택합니다. 종료일에 받은 문자까지 포함됩니다.
4. 발신자를 선택하면 해당 기간의 받은 문자가 표시됩니다.
5. **인쇄 / PDF 저장**으로 미리보기를 열고 **인쇄 / PDF**를 누릅니다.
6. Android 인쇄 화면에서 **PDF로 저장** 또는 휴대폰에 설정된 프린터를 선택합니다.

화면은 최신 문자부터, 인쇄 문서는 오래된 문자부터 표시합니다. 대한민국 `+82` 번호와 같은 국내 `0` 시작 번호는 같은 발신자로 묶습니다. 같은 연락처에 여러 번호가 등록된 경우 각 번호의 문자 목록을 따로 표시합니다. 새로 받은 문자는 **새로고침**으로 읽습니다.

## 지원 범위

- 받은 SMS, 연락처 이름 표시, 이름·번호 검색, 날짜 필터, A4 인쇄 미리보기와 PDF 저장
- MMS(사진·첨부 문자), RCS(채팅+), 보낸 문자, 카카오톡, 삭제된 문자는 지원하지 않습니다.
- 프린터 출력은 Android 인쇄 서비스에 등록된 프린터를 사용합니다. 제조사 인쇄 플러그인이 필요할 수 있습니다.
- 앱에는 인터넷 권한이 없으며 문자와 연락처를 서버에 전송하지 않습니다. Android 인쇄 서비스는 선택한 프린터에 문서를 전달합니다.
- 문자 읽기 권한은 민감한 권한입니다. 기기·설치 경로의 정책에 따라 허용이 제한될 수 있습니다. Google Play 배포는 별도의 SMS 권한 정책 검토가 필요합니다.

## 개발

Android Studio에서 이 폴더를 열고 Android SDK 35를 설치합니다. `local.properties`에 SDK 경로를 설정하거나 `ANDROID_HOME`을 지정합니다.

```bash
./gradlew :app:assembleDebug :app:testDebugUnitTest :app:lintDebug
```

APK: `app/build/outputs/apk/debug/app-debug.apk`

`adb install -r app/build/outputs/apk/debug/app-debug.apk`로 연결된 테스트 기기에 설치할 수 있습니다. 디버그 APK는 테스트용이며, 배포용 서명키는 포함하지 않습니다.

## 실제 기기 확인 항목

- 문자 권한 거절 시 안내가 표시되고, 연락처 권한 없이 번호로 조회할 수 있는지
- 연락처 이름, 여러 발신자, 긴 문자·한글·줄바꿈, `+82` 번호가 올바르게 표시되는지
- 날짜 범위의 첫날·마지막 날이 포함되는지
- 인쇄 미리보기와 PDF에서 본문·날짜·줄바꿈·페이지 나눔이 유지되는지
- 실제 프린터로 출력되는지

단위 테스트는 번호 정규화, 기간 경계, 문자 정렬, HTML 특수문자 처리 및 줄바꿈 보존을 확인합니다. 휴대폰 SMS 저장소 및 실제 프린터 연동은 기기에서 별도로 확인해야 합니다.
